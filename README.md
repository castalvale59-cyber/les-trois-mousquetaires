# Les Trois Mousquetaires

Un site très simple avec un jeu du train (façon Snake).

## Lancer le site

Ouvre `index.html` dans ton navigateur. Rien à installer.

## Jouer

- **Flèches** ou **ZQSD** : diriger le train
- **Espace** : lancer une partie / pause
- Sur mobile : boutons fléchés ou glisser le doigt sur le plateau

Le record est gardé dans le navigateur.

## Morpion

Page `morpion.html` (lien « Morpion » en haut du site).

- Contre l'ordi ou à deux sur le même écran
- Clic sur une case, ou touches **1 à 9** (disposition du pavé numérique)
- Le perdant commence la partie suivante
